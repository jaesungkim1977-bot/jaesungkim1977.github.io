# 혁신 항암신약 연구실 홈페이지

UST · 한국원자력의학원 혁신 항암신약 연구실 (Cancer X) 정적 홈페이지입니다.

## 내용 수정
모든 문구와 목록은 `data/content.js` 한 파일에 있습니다.
- `verified: false` 인 항목은 화면에 "예시" 배지가 붙습니다. 실제 자료로 바꾼 뒤 `true`로 바꾸세요.

## 구조
- `index.html` 페이지 뼈대
- `css/style.css` 디자인
- `js/hero.js` 메인 화면 세포 애니메이션
- `js/main.js` 데이터를 화면에 그리는 코드

## 배포
GitHub Pages: Settings → Pages → Branch `main`, 폴더 `/ (root)`.
